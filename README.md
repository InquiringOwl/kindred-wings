# Kindred Wings

The birds of San Francisco — sorted by size and color, with male, female and young drawings, when they're in town, what they might mean (after Ted Andrews, paraphrased), your own meanings over time, and a sightings journal. Plus "Beyond birds" for the animals that find you in other ways.

**Open the app:** https://inquiringowl.github.io/kindred-wings/

Install it: in Chrome, click the install icon at the right of the address bar; in Safari, choose File › Add to Dock. The app checks for updates on its own and shows a banner when a new version is ready.

Your journal stays in your browser (Settings › Save a backup file now and then). Nothing personal is stored in this repository.

## Releasing

```
scripts/release.sh patch "What changed"
```

GitHub Actions deploys to Pages in about a minute. See `CLAUDE.md` for how the project is put together.
